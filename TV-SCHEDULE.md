# Расписание на телевизоре

Откройте `/Health-Plus/tv-schedule` на том же сайте, где работает админ-панель.
Ссылка также есть в разделе админ-панели «Врачи и расписание».
Наведите указатель в правую нижнюю часть таблицы или используйте Tab, чтобы
выбрать «На весь экран». На компьютере можно нажать F11.

- 21 врач распределяется на три блока по семь строк. Смена — каждые 10 секунд.
- При добавлении более 21 врача появляются дополнительные блоки: никто не скрывается.
- Врачи, кабинеты и расписание текущей недели заново запрашиваются каждые 10 секунд.
- Расписание привязано к конкретным датам. Его нужно заполнить на текущую неделю
  в админ-панели. Прочерк означает, что приём не указан. Данные с фотографий
  автоматически в базу не записываются.
- Время и календарь используют часовой пояс Алматы. Часы устройства должны быть
  синхронизированы. Воскресенье появляется, если на него есть приём или сегодня воскресенье.
- Погода Алматы запрашивается у Open-Meteo каждые 15 минут. При недоступности
  источника отображается соответствующее сообщение. Данные старше часа скрываются.
- При сбое API сохраняются последние полученные данные с предупреждением.
  После смены недели старые часы приёма не показываются для новых дат.

## Подключение с другого устройства

Телевизор и админ-панель должны использовать один API и одну базу данных.
В production задайте `REACT_APP_API_URL` с доступным телевизору HTTPS-адресом API
перед сборкой. Если переменная не задана, используется адрес сервера сайта
на порту 8080; `localhost` на телевизоре не является адресом компьютера.
В `ALLOWED_ORIGINS` API должен быть указан фактический origin сайта.
Не размещайте API без необходимых настроек доступа в публичной сети.

Для проверки: `npm test -- --watchAll=false --runInBand`, затем `npm run build`.
